## Blackbox Project
This project models a complex data relationship system. *_training_data.txt contains the raw input vectors and targets used to train the model, while engine_model_weights.txt stores the optimized parameters derived from that training process. pro.cpp then applies these loaded weights to perform forward passes on new data, and un_history.txt keeps an ongoing audit log of all system execution runs and their performance metrics.
